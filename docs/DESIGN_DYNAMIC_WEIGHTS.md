# DESIGN: динамическая подгрузка весов MoE по орбите embedding

**Версия:** `dynamic_weight_orbit_v13`  
**Статус:** проектирование (сначала мысль, потом код/тесты)  
**Связь:** `EMBEDDING_PROTOCOL.md`, UCL, фазы 3–4 (Expert-Hit / prefetch), правило эмерджентности  

---

## 0. Зачем пересматривать блокер фазы 5

Раньше: «нет полного V2-Lite в RAM → BLOCKED».  

Это **статичное** мышление. Система у нас **динамическая** (агент↔среда, орбита, S_env, sleep).  
Веса должны жить по тем же правилам: **нужное — в орбите и в памяти; лишнее — не резидентно**.

На Mac 16GB полный MoE не нужен сразу. Нужен **динамический residency** по предсказанной орбите экспертов из `h`.

---

## 1. Локальные процессы (операционный слой)

Перед скачиванием шарда / live-hook / длинным прогоном:

```
probe → if busy: wait → when free: run
```

Реализация-хелпер: `_shared/process_gate.py`  
(не параллелить с чужим `run_all` / `hf download` / нашим бенчмарком).

---

## 2. Три слоя «веса» (разделить!)

| Слой | Что | Резидентность |
|---|---|---|
| **L0 Index** | `model.safetensors.index.json` + карта `tensor→shard` | всегда (МБ) |
| **L1 Spine** | embed (или поток), norm, attention/MLA текущего окна, **router**, **shared experts** | держать / подгружать по слою |
| **L2 Orbit** | веса **routed** экспертов из `O_t = Route(h)` | только hot-set; prefetch по горизонту |

Ошибка фазы 5: требовали L0+L1+L2 целиком до первого шага.  
Правильно: L0 сразу; L1 по мере навигации по слоям; L2 = орбита из embedding-языка.

---

## 3. Цикл = тот же UCL, но объект — тензоры экспертов

На токене `t` с residual/embed `h_t`:

1. **Attend (Route):** предиктор по `h` + S_env → орбита экспертов `O_t` (и горизонт `O_{t:t+H}`).  
2. **Prefetch (Assign environment):** для каждого `e ∈ O` — если тензора нет в hot-store → поставить в очередь загрузки шарда/слайса.  
3. **Exec:** router (живой или modeled) выбирает true set `T_t`; считаем только экспертов в hot ∪ sync-miss.  
4. **Deposit:** усилить S_env[e] для использованных; miss → штраф / усиление предикта.  
5. **Sleep / evict:** эксперты с массой S_env ниже **локального mean** поля → выгрузить из RAM (как sleep prune троп).  

Нет magic «держать 8 экспертов»: размер hot-set **эмерджентен** из поля использования.

---

## 4. Как грузить «кусок» без полного модели

Практическая схема (DeepSeek safetensors):

1. Скачать **только index** (лёгкий).  
2. По имени тензора (`…experts.{id}.…`) узнать shard.  
3. `safetensors.safe_open(shard)` → `get_tensor` **только** нужных ключей эксперта.  
4. Кэш: `expert_id → {param_name: tensor}` на CPU/MPS; LRU/S_env-evict.  
5. Router/shared — отдельные ключи, подгружаются один раз на слой или pinned.

Скачивание шарда с Hub — тоже **по требованию** (первый miss по файлу), не «все 4 шарда заранее».

---

## 5. Метрики (эмерджентные, без magic PASS)

Ряды по токенам / шагам:

- `hit_pred` vs `hit_uni` → wins>losses  
- `miss_bytes` (sync load) pred vs cold/uni → wins>losses на «меньше miss»  
- `resident_bytes` — наблюдение, не фиксированный бюджет-PASS  
- `evict_count` после sleep  

Структурные факты V2-Lite (64 routed, 2 shared, top-6) — ок; пороги PASS — нет.

---

## 6. Что это меняет в дорожной карте

| Было | Стало |
|---|---|
| Фаза 5 = полный live model | Фаза 5a = **dynamic loader + index + 1 expert slice smoke** |
| Блокер «16GB / нет весов» | Блокер только если **нет сети/доступа к одному шарду** или index |
| Prefetch bytes (фаза 4) modeled | Фаза 5b = те же метрики на **реальных** байтах шардов |

Фаза 6 UCL — после того как L2 orbit реально двигает residency.

---

## 7. Риски (честно)

- Первый доступ к эксперту = холодный shard download (долго) — это **измеряемый miss**, не провал идеи.  
- На Mac MPS/CPU: не обещать wall-clock ×100.  
- Неполный Chat-кэш: index есть, шарды missing → dynamic download **может** чинить по одному файлу; спрашивать пользователя перед большим трафиком.  
- Live router без attention stack даст только affinity по загруженному `gate` — для Expert-Hit этого достаточно на 5a; полный forward — позже.

## 8. Следующий шаг реализации (после ок пользователя / без параллели)

1. `_shared/process_gate.py` — wait-for-idle.  
2. `_shared/dynamic_expert_store.py` — index, get_expert(e), evict_by_s_env.  
3. Smoke: загрузить index V2-Lite (или Chat), **один** expert tensor on demand (с подтверждением download).  
4. Не гонять полный бенчмарк, пока smoke не зелёный.

## 9. Простыми словами

Мы не тащим в память всего «кита».
