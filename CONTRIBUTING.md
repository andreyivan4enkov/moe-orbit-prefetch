# Contributing

1. Keep **Object A** scope (MoE expert orbit / residency). Do not mix Object B (chat topology / RLM) into this repo.
2. Do not commit model weights or secrets.
3. New claims need a lab artifact under `results/` or a failing note — no invented PASS.
4. Prefer emergent local comparisons (`wins > losses`) over magic numeric PASS thresholds.
5. Open an issue before large design changes.
